目录与 pyproject 布局
---------------------
仓库采用 src 布局：实现包位于 src/review，唯一实现文件是 src/review/audit.py，测试位于 tests/test_audit.py。pyproject.toml 在 tool.pytest.ini_options 中设置 pythonpath 为 src，pytest 因此可以直接导入 review.audit，不需要 conftest.py。项目声明 Python 3.9 及以上，运行时依赖为空。

tests 不可修改
--------------
tests 目录是验收基准，不能修改、删除、重命名、跳过或用 xfail 标记任何测试，也不能在测试侧补实现。允许修改的范围只有 src/review/audit.py：按第一行给出的顺序修掉 10 个缺陷，并保留 8 个公开函数签名。

修复提示
--------
权限记录按主体、资源、动作和来源描述。逻辑权限只由主体、资源、动作三元组确定，来源只用于追溯。复核结果必须按逻辑权限去重，同一权限的多个来源只能报一次。快照对比要同时给出新增、删除和来源变更。孤儿判断必须读取目录状态，已离职和目录中不存在的主体都属于孤儿。高危规则必须在资源和动作两个维度上精确匹配。审批必须同时满足主体、资源和动作范围，并且签发时间不能早于 now 减 ttl。每批复核必须使用自己的快照和目录。
